# Monoxide Desktop (fan made)

A desktop application for accessing [Monoxide](https://monoxide.dev) without needing to open a separate browser.

## Features

- Desktop experience powered by Electron
- Built-in ad blocking
- Persistent session and saved settings
- Ronoxide access
- Cloaked Mode warning on startup

## Installation

1. Open the [Releases](../../releases) page.
2. Download the latest Monoxide Desktop installer.
3. Run the `.exe` installer.
4. Launch Monoxide Desktop.

## Requirements

- Windows 10 or Windows 11
- Internet connection
